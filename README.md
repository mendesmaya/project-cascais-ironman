# Iron Hunters · Cascais

Planeador com design adaptado a telemóveis e as funcionalidades originais: comparação de estações, mapa GPX, cenários de passagem e impressão / PDF.

## Horários CP

Atualizado em 14/10/2026 para sábado, 17/10/2026, com o horário de fim de semana em vigor desde 28/09/2026. Inclui apenas viagens integralmente ferroviárias. Os autocarros de substituição noturnos não são calculados.

Fonte: https://www.cp.pt/info/documents/d/cp/comboios-urbanos-lisboa-cascais-1

Avisos: https://www.cp.pt/info/w/linha-de-cascais-servico-rodoviario

A CP anuncia serviço rodoviário entre Caxias e Cascais a partir das 20h50 aos sábados. Não foi encontrado aviso específico para a manhã da prova na consulta de 14/10/2026. Confirma os avisos antes de sair. As estimativas do atleta e caminhadas continuam aproximadas.

## Abrir

Abre index.html no navegador ou serve a pasta com python -m http.server 8000.
